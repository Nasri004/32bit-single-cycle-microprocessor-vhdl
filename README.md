# 32bit-single-cycle-microprocessor-vhdl
32-bit single-cycle Harvard microprocessor designed in VHDL

This repository presents the design and simulation of a 32-bit single-cycle microprocessor implemented using VHDL (VHSIC Hardware Description Language).
The project was carried out as part of the Programmable Logic Circuits and VHDL Programming module and aims to provide a practical and educational implementation of fundamental microprocessor concepts.

The processor follows a Harvard architecture, with separate instruction and data memories, and executes each instruction within one clock cycle. The design is fully modular, simulated, and validated using ModelSim, allowing functional verification before any physical FPGA implementation.
